# **App Name**: Posthog Personality Quiz

## Core Features:

- Interactive Quiz: Implement a multi-step quiz with 7 multiple-choice questions. The questions should be themed around developers, startups, and PostHog-style humor.
- Personality Assignment: Based on quiz answers, assign users one of six personality types: Open Source Overlord, Startup Sadboi, Data Gremlin, Feature Flag Fairy, Product Pirate, or Funnel Witch. Each answer should contribute points toward one or more personality types.
- Results Page: Display the quiz result with the assigned personality's name, emoji, a 2-3 sentence description, and a "Share your result" option.

## Style Guidelines:

- Use the same primary color as PostHog's website to maintain brand consistency.
- Complement the primary color with lighter shades to create a clean and modern feel.
- A vibrant green (#90EE90) for interactive elements and highlights, drawing attention to key actions.
- Ensure readability and alignment with PostHog's brand aesthetic.
- Use simple, recognizable icons to enhance the quiz-taking experience.
- Subtle animations and transitions to create a delightful and engaging user experience.
- A clean, single-column layout for easy navigation and mobile responsiveness.
